# Barbería NegociosPyme

Primera base Android de la app de barbería.

## Incluye
- Login demo
- Dashboard principal
- Agenda
- Clientes
- Caja
- Barberos
- Servicios
- Configuración
- QR de reservas como módulo preparado
- Diseño oscuro/dorado
